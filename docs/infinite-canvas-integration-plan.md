# Tapdance 无限画布集成与迁移记录

## 目标与基线

首页提供第四种项目类型“无限画布”，创建和恢复后直接进入画布。按用户要求，以 NiegeIP 已有成熟画布的交互和编辑模块为迁移基线，使用 Tapdance 的配色、项目持久化、模型配置和资产库。

原始简化版本曾参考 `basketikun/infinite-canvas`（MIT）；此次迁移的实际来源为本机正式仓库 `NiegeIP/niegeip-frontend/apps/web/src/pages/infinite-canvas` 及 `apps/web/src/features/editor`，读取时 HEAD 为 `9ca5b2b5bee7c971c71592b7b434747d1e1d7f6c`。未修改来源仓库。迁入文件保留来源说明。

## 已迁入的编辑能力

| NiegeIP 模块/能力 | Tapdance 接入 |
|---|---|
| canvas.utils | 框选、Shift 增减选择、组原子选择与移动、吸附/辅助线、视图适配、指针缩放、滚轮平移、无重叠新增位置 |
| canvas.layout | 保留按生成依赖排列及环路处理逻辑，支持组内布局和重复整理稳定性 |
| canvas.clipboard | 重映射节点/组/内部连线、复制粘贴与副本命名；副本不继承正在运行的任务 |
| canvas.groups | 混合节点成组/拆组、图片组合引用、拆组保留引用、删除组引用连线 |
| canvas.recycle-bin | 删除保留节点和关联边、恢复、分别删除/恢复端点时找回连接、永久删除 |
| editHistory / useEditHistory / shortcuts | 撤销重做、拖动合并、编辑器快捷键隔离；适配 Tapdance 状态并修复分组编辑期间异步结果被撤销的问题 |
| CanvasTools / CanvasShortcutPanel | 原工具布局、小地图定位、资产列表、显示/隐藏连线、选择/抓手、缩放与快捷键面板 |
| CanvasAddMenu | 右键/双击新增菜单、键盘操作；保留 Tapdance 的文字节点 |
| 媒体卡片 | 紧凑媒体呈现、自适应尺寸、上下游连接、新增、预览、下载、替换、资产库保存 |

画布独占应用工作区，保留桌面标题栏。顶部包含返回项目列表、项目名称、模型设置、主题切换和创建操作。所有画布颜色从现有 Studio 主题变量派生。

## Tapdance 服务适配

- `Project.canvasFlow` 保存节点、连线、视口、组、参考顺序、回收站及已提交视频任务标识。旧项目自动补默认字段；回收站内容计入项目非空判定。
- 文字/图片/视频沿用全局模型设置与当前模型服务。图片/视频结果自动尝试写入现有本地资产库；失败保留可用结果和明确提示，也可手动保存。
- 参考排序影响生成输入顺序；图片组引用会展开为当前成员，替换素材后无需重新连接。
- 视频任务只保存 provider、任务编号和 mock 标识，不保存凭据。重开项目继续查询原任务；超时保留编号供继续查询。同步文字/图片请求在页面退出后无法重连，重开时明确显示中断状态，避免无限加载。
- 上传、粘贴和拖放支持图片、视频、音频；节点替换检查媒体类型。音频当前支持导入和播放，没有独立音频合成服务。
- 资产库列表、项目封面、项目分组和媒体统计识别画布产物。资产库保存回写画布节点 URL。
- 弹窗与下拉复用 StudioModal / StudioSelect。CanvasModal 补充焦点圈定、编辑器隔离与焦点恢复；StudioSelect 转发 ARIA 命名属性。

## 尚不能宣称完全 1:1 的边界

以下属于 NiegeIP 后端/业务能力，当前迁移没有伪造对应按钮或效果：

- 图片/视频超分及配套工作流、独立音频合成。
- 云端多用户保存版本冲突、NiegeIP 积分报价/扣费和任务取消/队列业务。
- 肖像授权、自动预检、IP 素材库和服务端原图签名续期。
- 服务端视频截帧及 NiegeIP 云端素材 ID/授权协议。提示词素材提及组件已复制并适配为画布节点 ID。

现有 Tapdance 视频配置、供应商费用预估、生成任务与资产库服务继续复用。若需要上述业务能力完全等价，需要先补齐或接入相应服务契约；这不属于仅换主题色能完成的迁移。

## 验证

使用 Node 25.9.0 和锁定依赖；没有更新依赖版本。

- `npm run lint`：TypeScript 检查。
- `npm test`：全量单元测试，覆盖组选择、吸附、环路布局、引用顺序、跨次恢复、任务安全复制和异步结果的撤销保护。
- `npm run build`：生产构建。
- `tests/e2e/infinite-canvas.spec.ts`：使用模拟持久化桥接和 mock 模型，覆盖项目创建/重开、分组复制、撤销重做、回收站、滚轮/缩放、输入快捷键、错误提示、素材上传、引用排序、视频生成、主题和窄屏。
- 画布目录的 UI 静态审查通过；全仓审查发现的原有其他页面 textarea/原生 select 和全局 scrollbar 问题未扩展修改。

浏览器验证不消耗真实模型额度，也不证明真实服务商 API 已端到端通过。真实生成和资产落盘仍需要用户本地桥接及有效模型配置。

## 创作组件补全

修复上一轮遗漏：图片/视频节点选中后，直接显示 NiegeIP 的底部创作组件，无需再打开高级配置才能输入提示词。补全节点正文、名称和媒体区域的点击选择。

- 迁入 `PromptMentionEditor`、`promptMention.utils`、`CreationGenerationControls` 和 `CreationParameterPanel`；模型下拉通过 `CreationDropdown` 适配已有 StudioSelect。
- 保留提示词本地撤销、IME、@ 素材菜单、缩略图标签、参数弹层和面板展开交互。
- 模型、比例、图片数量、视频时长/分辨率/格式及可用的音频选项接入 Tapdance。批量图片实际执行对应次数，返回独立结果节点。未接入的图片分辨率/画质选项不会展示为可用功能。
- @ 提及采用持久化节点 ID；提交时按当前参考顺序转换成服务商可识别的图片/视频/音频标签。复制节点时重映射内部提及，保留有效外部提及。
- 添加参考素材会连接到当前创作节点，并保留目标选中状态。
- 增加直接图片生成、批量结果、点击重选、直接视频生成、@ 提及、参数弹层、展开/收起和窄屏浏览器覆盖。所有生成验证使用 mock。

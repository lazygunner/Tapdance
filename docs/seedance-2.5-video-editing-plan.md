# Seedance 2.5 视频编辑功能规划

> 规划日期：2026-08-10  
> 适用项目：Tapdance  
> 依据：[Seedance 提示词指南](https://www.volcengine.com/docs/82379/2222480?lang=zh)、[创建视频生成任务 API](https://www.volcengine.com/docs/82379/1520757?lang=zh)（线上 API 文档最近更新时间：2026-08-07）

## 1. 产品结论

Seedance 2.5 的“视频编辑”应被产品化为**基于自然语言的生成式视频改写**，而不是传统剪辑器。首版聚焦三类高确定性任务：

1. 增加元素：在指定时间、指定空间位置增加对象。
2. 删除元素：删除目标对象，其他内容尽量保持不变。
3. 替换元素：把原视频中的对象替换成参考图中的对象，尽量保持动作、运镜和时序不变。

延长视频、拼接补间、动作/运镜/特效参考虽然复用同一个 API，但用户意图、参数规则和验收方式不同，应继续作为独立功能，而不是混入“视频编辑”首版。

## 2. 官方能力与硬约束

### 2.1 Seedance 2.5 通用能力

- 多模态参考：最多 30 张图片、10 个视频、10 个音频。
- 参考视频总时长不超过 30 秒，参考音频总时长不超过 30 秒。
- 支持有声/无声、最长 30 秒连贯直出。
- 支持 MP4、MOV 输入；参考视频单文件不超过 200 MB，帧率 24–60 FPS。
- Seedance 2.5 输出分辨率为 480p 或 720p。
- 输出可选 MP4 或 MOV；官方推荐视频编辑、视频延长使用 MOV 作为输入和输出。
- 任务为异步任务：创建后返回 `id`，再通过查询接口或回调获取状态与结果。
- 当前产品成本估算单价：包含视频输入 **42 元 / 百万 tokens**，不含视频输入 **70 元 / 百万 tokens**。

### 2.2 视频编辑任务专属约束

- 待编辑视频时长必须在 4–30 秒。
- `duration` 必须为 `-1`，不可指定目标时长。
- 输出时长自动与输入视频基本一致，可能比输入短约 0.4 秒。
- `ratio` 必须为 `adaptive`，输出自动继承待编辑视频的宽高比。
- 首版应只允许 1 个“待编辑主视频”；其他素材作为替换对象、风格、声音等辅助参考。这样能降低任务类型误判和提示词歧义。

### 2.3 肖像与可信素材

- 不可直接提交普通的含真人人脸参考图或参考视频。
- 可使用平台预置虚拟人像、已授权真人素材，以及本账号近 30 天内由 Seedance 2.5/2.0 生成的可信原始视频。
- 产品必须在提交前提示素材合规风险，并区分“普通上传”“可信模型产物”“asset:// 授权素材”。

## 3. 目标用户与核心场景

### 3.1 目标用户

- 广告创作者：替换商品、包装、Logo、桌面陈列和背景元素。
- 短视频创作者：删除穿帮物体、增加氛围元素、修改服装或道具。
- AI 导演/剪辑师：保持原始镜头调度，仅迭代局部视觉内容。

### 3.2 首版场景

| 场景 | 用户输入 | 系统生成的核心指令 |
|---|---|---|
| 增加元素 | 主视频、时间位置、空间位置、元素描述/参考图 | 在视频1的指定时间与位置增加目标元素，其他内容保持不变 |
| 删除元素 | 主视频、目标对象、可选时间范围 | 删除视频1中的目标对象，保持原有动作、运镜、构图和时序 |
| 替换元素 | 主视频、原对象描述、参考图/新对象描述 | 将视频1中的原对象替换为图片1中的对象，动作和运镜不变 |

不在首版范围：蒙版绘制、逐帧跟踪、精确关键帧控制、传统多轨剪辑、无限撤销、多个主视频的批量编辑。

## 4. 用户流程

```mermaid
flowchart LR
    A["选择原视频"] --> B["自动检测格式、时长、画幅和人脸风险"]
    B --> C["选择增加、删除或替换"]
    C --> D["填写目标、时间位置、空间位置和保持项"]
    D --> E["添加参考图、参考音频等辅助素材"]
    E --> F["预览编译后的 Seedance 指令与锁定参数"]
    F --> G["上传 TOS 并提交异步任务"]
    G --> H["轮询 queued/running/succeeded/failed/expired"]
    H --> I["原片与结果对比"]
    I --> J["保存版本、再次编辑或设为项目素材"]
```

### 4.1 入口

- 生成结果卡片：增加“用 Seedance 2.5 编辑”按钮。
- 素材库视频详情：增加“AI 编辑”操作。
- 极速成片：保留现有功能模板，但选择“视频编辑”时切换到专用表单。

### 4.2 编辑表单

表单按操作类型动态展示：

- 主视频：固定一个，支持本地上传、素材库、远程 URL、`asset://`。
- 编辑类型：增加 / 删除 / 替换。
- 目标对象：自然语言描述。
- 时间范围：可选；使用播放器打点生成“从 00:03 到 00:06”的自然语言，而不是伪装成模型的精确时间轴参数。
- 空间位置：可选；如“画面左下角”“人物右手中”。
- 替换参考：替换模式可添加一张或多张参考图，并显示 `图片1`、`图片2` 映射。
- 保持项：默认勾选动作、运镜、构图、时序、非目标元素；这些会编译进提示词，但 UI 应注明“模型尽量保持，不是像素级保证”。
- 声音：默认保持有声输出；允许明确生成无声版本。
- 输出：默认 `720p + MOV`；可切换 `480p/720p` 和 `MP4/MOV`。
- 锁定参数：画幅显示“继承原视频”，时长显示“继承原视频”，不可编辑。

### 4.3 提交前确认

显示一张请求摘要卡：

- 待编辑主视频及检测到的时长、画幅、编码、FPS。
- 所有参考素材及 `图片n/视频n/音频n` 顺序。
- 最终提示词。
- `ratio=adaptive`、`duration=-1`、分辨率、输出格式、有声/无声、水印。
- 费用预估区间；在任务完成前标明为估算值。
- 肖像和版权风险提示。

## 5. 提示词编排

### 5.1 基础公式

沿用官方指南的结构：主体与动作 + 环境与美学 + 运镜与音频。涉及多模态素材时必须显式使用 `图片1`、`视频1`、`音频1` 指代，并保持 UI 顺序与 API `content` 顺序一致。

### 5.2 模板

增加：

```text
在视频1的{时间位置}{空间位置}增加{元素描述}。
新增元素需符合原画面的透视、光照、运动和遮挡关系。
除指定修改外，保持原视频的人物动作、运镜、构图、时序、声音和其他元素不变。
```

删除：

```text
删除视频1{时间位置}中的{目标对象}，自然补全被遮挡的背景。
除指定修改外，保持原视频的人物动作、运镜、构图、时序、声音和其他元素不变。
```

替换：

```text
将视频1{时间位置}中的{原对象}替换为图片1中的{新对象}。
保持新对象与原对象的尺寸、位置、动作轨迹、透视、光照和遮挡关系一致。
除指定修改外，保持原视频的人物动作、运镜、构图、时序、声音和其他元素不变。
```

### 5.3 诊断规则

- 未出现 `视频1`：自动补齐并提示用户。
- 替换模式没有 `图片1` 或没有新对象描述：禁止提交。
- 同时要求“保持运镜不变”和“改成全新运镜”：提示冲突，不静默改写。
- 编辑要求过多：建议拆成多个版本迭代，降低一次性生成偏差。
- 中文超过 500 字或英文超过 1000 词：提示压缩。

## 6. Tapdance 当前基础与差距

### 6.1 已具备

- 已配置 Seedance 2.5 模型 ID：`doubao-seedance-2-5-260628`。
- 已有 30 图 / 10 视频 / 10 音频、30 秒、480p/720p、MP4/MOV 能力配置。
- 已有 `video_edit` 模板，以及 2.5 下 `ratio=adaptive`、`duration=-1` 的归一化逻辑。
- 已有视频/音频上传到 TOS、素材排序、提示词引用 token、Ark 异步提交、轮询、取消、输出持久化和任务日志。

### 6.2 必须修正

1. `video_edit` 当前会把模型级 `maxVideos=10` 覆盖到模板上，首版应校验为“恰好 1 个主视频”。
2. 当前编译器只把参考图的 `label` 写进提示词；视频与音频的语义标签没有进入最终提示词。应统一生成稳定的 `图片n/视频n/音频n` 映射。
3. 当前 Seedance 2.5 仍被校验为“不允许纯音频输入”，与最新 API 文档冲突。虽不阻塞视频编辑，但应一并修正能力矩阵和测试。
4. `duration=-1` 的费用估算不能按 4 秒兜底，应使用主视频检测时长估算。
5. 当前 UI 只是通用“功能模板”下拉框，缺少编辑类型、目标对象、时间位置、保持项和原片/结果对比。
6. 视频元数据缺失时仍可能提交；视频编辑必须先完成时长、尺寸、帧率和格式检测。
7. 需要给 `SeedanceApiTask`/调用日志补充编辑来源、版本关系、输入视频快照和最终编译提示词，便于复现与回滚。

## 7. 技术设计

### 7.1 领域模型

在现有 `SeedanceDraft` 上增加专用的编辑意图，不另外复制一套提交协议：

```ts
type SeedanceEditOperation = 'add' | 'remove' | 'replace';

interface SeedanceVideoEditIntent {
  operation: SeedanceEditOperation;
  targetDescription: string;
  replacementDescription?: string;
  timeRange?: { startSec?: number; endSec?: number };
  spatialHint?: string;
  preserve: Array<'motion' | 'camera' | 'composition' | 'timing' | 'audio' | 'other_elements'>;
  sourceVideoAssetId: string;
}
```

建议把 `editIntent` 挂在 `SeedanceDraft`，由专用编译器生成自然语言，再复用现有 `compileSeedanceRequest()`、`createSeedanceTask()` 和任务轮询。

### 7.2 请求映射

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    { "type": "text", "text": "将视频1中的香水替换为图片1中的面霜，动作和运镜不变。" },
    { "type": "video_url", "video_url": { "url": "https://.../source.mov" }, "role": "reference_video" },
    { "type": "image_url", "image_url": { "url": "https://.../product.png" }, "role": "reference_image" }
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": -1,
  "output_format": "mov",
  "generate_audio": true,
  "watermark": false
}
```

### 7.3 状态与版本

- `sourceAssetId`：原视频。
- `parentVersionId`：上一次编辑结果，支持链式迭代。
- `editIntentSnapshot`：用户表单快照。
- `compiledPrompt`：实际请求提示词。
- `requestSnapshot`：脱敏后的请求参数与素材映射。
- `resultAssetId`：持久化后的生成视频。
- 状态：draft / uploading / queued / running / succeeded / failed / expired / cancelled。

## 8. 分阶段实施

### Phase 0：协议正确性（P0，约 1–2 个开发日）

- 修正纯音频能力矩阵。
- 视频编辑强制单主视频、4–30 秒、`duration=-1`、`ratio=adaptive`。
- 修正 `duration=-1` 费用估算。
- 补齐视频/音频引用映射和单元测试。

验收：非法请求在前端可解释地拦截；合法请求快照与官方协议一致。

### Phase 1：视频编辑 MVP（P0，约 4–6 个开发日）

- 新增专用编辑面板和三个操作模板。
- 支持播放器时间打点、空间位置、保持项和替换参考图。
- 复用 TOS 上传、Ark 提交、轮询、取消、持久化。
- 结果页提供原片/结果并排或滑动对比，以及“再次编辑”。

验收：用户可从已有视频出发，完整完成增加、删除、替换并保存结果。

### Phase 2：版本化与可观测性（P1，约 3–5 个开发日）

- 编辑版本树、提示词与请求快照、失败原因分类。
- 对比播放同步、设为项目素材、回退到任一版本。
- 增加编辑任务转化、失败、重试、费用指标。

验收：任一结果可追溯到原片、操作意图、参考素材和请求参数。

### Phase 3：高级生成式编辑（P1/P2，约 4–6 个开发日）

- 视频向前/向后延长。
- 多视频轨道补齐和衔接。
- 动作、运镜、特效参考的专用表单。
- 批量变体：同一编辑意图生成多个版本后挑选。

## 9. 测试与验收清单

### 9.1 单元测试

- 三种编辑意图的提示词编译。
- 素材排序与 `图片n/视频n/音频n` 映射。
- 4 秒、30 秒边界；小于 4 秒和大于 30 秒拦截。
- 编辑任务只允许 `duration=-1`、`ratio=adaptive`。
- 480p/720p、MP4/MOV 枚举。
- 含人脸普通上传、可信产物、`asset://` 的不同提示路径。
- `duration=-1` 使用输入视频时长进行费用估算。

### 9.2 集成测试

- 本地文件上传 TOS后提交 Ark。
- queued → running → succeeded 全流程。
- failed / expired / cancelled 状态展示和重试。
- 生成结果下载并持久化到素材库。
- Electron 重启后恢复任务与版本关系。

### 9.3 产品验收

- 新用户无需理解 API 参数即可完成一次编辑。
- 提交前能看懂“会修改什么、会尽量保持什么”。
- 原片与结果可同步播放对比。
- 失败信息能区分素材、审核、配额、参数、网络和任务超时。

## 10. 关键指标

- 编辑面板到成功提交转化率。
- 创建任务成功率、生成成功率、审核拦截率、上传失败率。
- 首次结果采用率、再次编辑率、平均版本数。
- 平均生成耗时、P95 生成耗时、平均单次费用。
- 三种操作的成功率与采用率差异。

## 11. 建议的首版发布边界

首版只发布：

- Seedance 2.5 Ark API。
- 单主视频。
- 增加、删除、替换三种操作。
- 可选参考图。
- 480p/720p、MP4/MOV、有声/无声、水印。
- 原片/结果对比、保存版本、再次编辑。

这一边界能最大化复用 Tapdance 已有基础设施，同时把官方提示词指南里最清晰、最容易形成产品闭环的能力先做扎实。
